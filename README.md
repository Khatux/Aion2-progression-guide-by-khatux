# AION 2 — Progression Guide by Khatux

Sito pubblico della guida alla progressione di AION 2.

## Pubblicazione
Il file `index.html` è già pronto per GitHub Pages.

## Editor
La pagina pubblica è volutamente separata dal sistema di modifica. Per avere un vero editor senza codice che pubblichi le modifiche sullo stesso link serve collegare un CMS autenticato (es. Decap CMS/GitHub OAuth). Non viene inserito un falso editor basato su localStorage, perché quello cambierebbe solo il browser dell'utente e non la pagina pubblica.
